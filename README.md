# Тропа Ткачей

> **Ветка `v2` (в работе): переход на Phaser 4 + TypeScript + Vite + Preact.** Стек, план и состояние — `docs/V2_PLAN.md`, установка и команды — `docs/LOCAL_SETUP.md`. Игра v1.8 (Phaser 3) лежит в `legacy/` и остаётся эталоном; сайт собирается из `main`. Описание ниже относится к v1.8.

Кооперативная метроидвания в браузере. Кампания из четырёх глав: I «Мшистая Глубь» (Корнематка), II «Старая типография» (Миша), III «Кабинет музыки» (Владик), IV «Берлога Тимы» (Тима). В главах II–IV перед ареной есть коридор со скамьями и врагами. Враги, скамья-чекпоинт, лавка улучшений. Вся графика нарисована кодом.

**Играть:** https://rus25-dev.github.io/tropa-tkachei/

## Гонки Ткачей (v1.8)

Соревнование для двоих с отдельным организатором и зрителем. Организатор сам не играет: он создаёт **одну гонку в одной дисциплине** («Тропа целиком»), раздаёт ссылки, запускает общий отсчёт 3‑2‑1, при необходимости ставит техническую паузу, переигрывает, присуждает победу или отменяет своё последнее действие. Игроки играют каждый у себя (зерно общее: одинаковые враги и бусины), обсервер показывает обоих.

Меню: **Гонки Ткачей** → Создать гонку · Войти игроком по коду · Обсервер · Архив гонок. Ссылки: `?race=org`, `?race=play&room=КОД`, `?race=watch&room=КОД`.

1. Организатор открывает «Создать гонку» (или `?race=org`), копирует ссылку игрокам и ссылку обсервера. Комната живёт по коду вроде `K7P4Q`.
2. Игрок открывает ссылку, вводит имя (сравнение без учёта регистра и пробелов, подсказки уже известных имён; организатор может «Объединить игроков» в архиве) и жмёт «Готов». Лёгкий режим и замедление в гонке запрещены; версия игры у всех должна совпадать.
3. Организатор жмёт «Старт гонки»: игроки загружают забег, потом общий отсчёт и «Пошёл».
4. Обсервер (1920×1080) показывает две равные половины с картинкой игроков по телеметрии (~15 Гц), в центре табло (таймер по часам организатора, имена, маски, босс, разница времени), внизу — ленту событий. До старта — карточки игроков, после гонки — разбор: время, сплиты, урон боссам, DPS, полученный урон, лечения, точность, отбивы, идеальные увороты, оглушения, казни, самое длинное комбо, покупки.
5. Результат уходит в архив организатора (`localStorage`) в едином формате `{ id, date, version, discipline, settings, seed, players:[{ name, place, time, finalTime, dnf, stats, splits, eloBefore, eloAfter }], winner, events }`. Кнопка «Скачать races.json» отдаёт весь архив.

### Надёжность гонок и спидрана
- **Канал** (`src/race-net.js`): пульс каждые 2 с, тишина 7 с = связь потеряна; клиент переподключается сам с растущей паузой (0,3 → 8 с) и возвращается на то же место по личному ключу. События нумеруются: у клиента — по номеру `n`, у организатора — по общему журналу `g`; после обрыва недоставленное досылается, дубли отбрасываются, при потерянном кадре приём требует досылки. Телеметрия идёт без нумерации (важна последняя).
- **Игрок при обрыве** играет локально, время идёт, события копятся и уходят после возвращения связи; очередь переживает и перезагрузку вкладки. На табличке под таймером видно «связь потеряна, играем локально».
- **Организатор** пишет состояние гонки в `localStorage` (`tt_rc_org`): после перезагрузки страницы поднимает комнату с тем же кодом (если прежний id ещё занят на сервере — ждёт и пробует снова), места игроков, счётчики и ход гонки возвращаются; игроки и обсерверы переподключаются сами.
- **Обсервер** при подключении получает полный снимок гонки, не ставится на паузу при скрытом окне (состояние обновляется сетевыми сообщениями, а не кадрами; тихий звук и Web Locks держат вкладку активной) и догоняет по последней телеметрии. Chrome всё равно может прекратить рисовать полностью закрытое другим окном: для стрима держите окно обсервера на втором мониторе.
- **Восстановление забега по журналу ввода** (`src/journal.js`): логика идёт тиками по 1/60 с, поэтому забег = зерно + настройки + ввод по тикам. Журнал (сжатый, плюс действия интерфейса и контрольные хэши состояния) пишется в `localStorage` (`tt_jr`) раз в ~2 с. После падения или перезагрузки вкладки игрок заходит в ту же гонку (или «Спидран → Восстановить забег»), журнал воспроизводится без отрисовки и звука (≈7000 тиков в секунду), хэши сверяются; при расхождении забег не продолжается. Время простоя идёт в зачёт (RTA считается от настенного времени старта), забег помечается «восстановлен». Работает и для одиночного спидрана.

### Устройство гонок
`src/race-net.js` (сеть) · `src/race-org.js` (организатор, архив) · `src/race-play.js` (игрок) · `src/race-watch.js` (обсервер) · `src/race-stats.js` (статистика) · `src/journal.js` (журнал ввода). Проверки: `node tools/race-net-test.js` (сеть в Node с виртуальным временем: обрывы, дубли, перезагрузка организатора, «хаос» на 10 минут), `node tools/race-test.js` (организатор + 2 игрока + обсервер в отдельных страницах, обрыв связи, техпауза, восстановление игрока по журналу, перезагрузка организатора, финиш и архив), `node tools/journal-test.js`.

## Босс-тест

Пункт меню «3 · Босс-тест» сразу запускает бой с выбранным боссом (карточки боссов с личным рекордом, ← → — выбор; там же тренировка и старт с фазы 1/2/3) — в одиночку, вдвоём за одним компьютером или по сети.

### Миша Додик — «Старая типография»

На 2/3 и 1/3 здоровья камера переворачивается в вид сверху — фаза «Пропустите!»: три коридора со стенами и проходами, Миша идёт по одному из них, ведя рукой по стене. Встаньте у него на пути в подсвеченном коридоре — он крикнет «ПРОПУСТИТЕ!» и начнёт заново. Остановите его 3 раза (вдвоём — 4), и он выдохнется с открытым рюкзаком; если дойдёт до конца коридора — обрыв нити.

Миша швыряется печатными заглавными буквами (выкрикивает слово, и оно летит в вас по букве), роняет с потолка огромные буквы и таранит с разбега. В первых двух фазах его можно бить иглой (4 удара = 1 бутон здоровья), а дымовая бомба в открытый рюкзак у него на спине снимает целый бутон. В последней фазе (последняя треть здоровья) он застёгивает рюкзак на все замки: иглой не пробить, бить надо только дымовыми бомбами. Бомбы берутся из ящиков «ДЫМ» по краям арены (до трёх штук). Зайдите со спины, подловите его после тарана в стену или закиньте бомбу навесом через голову. Вдвоём проще: пока один отвлекает, второй бросает.

### Боссы 2.0 — три фазы
На 60 % и 30 % здоровья каждый босс входит в ярость: рёв, вспышка, все отлетают, снаряды исчезают, и полторы секунды он неуязвим. Дальше он становится быстрее, получает новые атаки, а музыка ускоряется.
- **Корнематка:** корни выстреливают из-под земли цепочкой к игроку (место вспыхивает заранее), в третьей фазе — двойные прыжки и корни в обе стороны.
- **Миша Додик:** после первого «Пропустите!» — «Диктант!»: стена букв падает сверху, ищи проём. После второго — застёгивает рюкзак, дымовухи отскакивают, пока ему не станет жарко.
- **Владик Скрипка:** нотный стан — пять линий во всю ширину, часть загорается, стой на безопасной (пол или парта); выпад смычком через весь класс, после него — окно для ударов. В третьей фазе ноты падают с потолка, ключей летит четыре.
- **Тима Пиво:** «Коллекторы, фас!» — бегающие сборщики долгов, режутся иглой за 2 удара; в третьей фазе ачивки-кубки падают сверху с отскоком, а после геймпада сразу идёт красное кольцо.

Реплики боссов и подсказки висят столько, сколько нужно, чтобы их дочитать, и встают в очередь, а не перебивают друг друга.

### Владик Скрипка — «Кабинет музыки»

Школьный класс с доской, партами и бордовыми шторами. Владик кричит «Я НЕ СКРИПКА!», швыряет скрипичные ключи-бумеранги (они возвращаются к нему), прыгает и разбрасывает ноты, а ещё бегает к шторам и мажет их слизью. Слизь жжётся, с неё капает; под шторой можно пройти низом, но прыгать в неё нельзя. Бьётся иглой; ноты можно срубить.

### Тима Пиво — «Берлога Тимы»

Диван, полка с бутылками, ящики и телевизор. Тима кидает бутылки — на полу остаются лужи пены, в которых медленно бегается; пьёт пиво и подлечивается (удар прерывает). «Банкротство!»: сверху падают печати «БАНКРОТ», мебель на 6 секунд изымают за долги, а половина нити уходит кредиторам. Приставочные атаки: геймпад на проводе крутится вокруг него, «красное кольцо» пускает по полу две волны, а саму приставку он швыряет с отскоками. Перед волшебной пылью Тима пару секунд чертит на полу светящийся круг — успейте подбежать: три удара, пока он чертит или вдыхает, и он чихнёт без ускорения. Иначе 8 секунд носится в полтора раза быстрее.

## Как играть вдвоём по сети

1. Оба открывают ссылку выше.
2. Первый игрок выбирает «2 · Кампания» → «Новая игра» → «Вдвоём по сети» → «Создать комнату» и отправляет другу код или ссылку.
3. Второй вводит код и нажимает «Войти» (или просто открывает присланную ссылку).

Соединение идёт напрямую между браузерами по WebRTC. Если сеть не пускает (серый IP, мобильный интернет, строгий NAT), трафик автоматически идёт через ретранслятор. Порты пробрасывать не нужно.

По сети каждый управляет своим героем раскладкой игрока 1. Хост (создатель комнаты) считает мир: врагов, босса, снаряды. Если хост закроет вкладку, игра у гостя закончится.

## С телефона

Откройте ссылку на телефоне и держите его горизонтально: сенсорное управление включится само.

- **Слева — стик**: коснитесь где угодно в левой части экрана и тяните. Стик вверх — удар вверх, оживить напарника, сесть на скамью; вниз в прыжке + удар — удар вниз с отскоком.
- **Справа — кнопки**: «Прыжок» (держите — выше), «Удар», «Рывок», «Лечить», а на арене Миши ещё «Бомба».
- Сверху — пауза. На Android первый же тап в меню включает полный экран и закрепляет горизонтальную ориентацию; если выйти из него, рядом с паузой появится кнопка ⛶. На iPhone полноэкранного режима у сайтов нет: поставьте игру на экран «Домой» (Поделиться → «На экран „Домой“») и запускайте с иконки — без панелей Safari.
- Поле игры подстраивается под пропорции экрана и видимую область браузера: обходит вырез/Dynamic Island и полоску «Домой», кнопки масштабируются под высоту экрана. Проверено на размерах iPhone 13 mini … 17 Pro Max, в том числе с открытой панелью Safari и после поворота. Работают все режимы, включая игру по сети: можно играть телефон против компьютера.
- Геймпад по Bluetooth тоже подхватывается.

## Удобства

- **Обновления**: игра сама проверяет `version.json` при запуске, при возврате в приложение и раз в 10 минут; если вышла новая сборка, появляется плашка «Обновить». Это важно для иконки на экране «Домой» на iPhone — без неё Safari долго показывает старую версию из кэша.
- **Музыка**: у меню, пещеры, Корнематки и каждого босса своя тема (генерируется на лету, без файлов). Громкость музыки и звуков — отдельно в настройках; в паузе музыка приглушается.
- **Спрыгнуть с платформы**: ↓ + прыжок (на телефоне — стик вниз + «Прыжок»).
- **Настройки** (пункт меню 7 или кнопка в паузе; разделы Звук, Экран, Управление, Игра, Прогресс): громкость, тряска экрана, лёгкий режим (8 бутонов здоровья вместо 5); на телефоне ещё вибрация, размер и видимость кнопок, раскладка для левши. Всё запоминается в браузере.
- **Сохранение на скамье**: глава продолжается с последней скамьи вместе с бусинами. Сбросить можно в настройках.
- **Кампания и «Продолжить»**: в сохранении — глава, скамья, бусины, способности и улучшения. После победы над боссом кнопка «Глава N →» ведёт дальше; по сети переход общий (ведёт хост).
- **Лавка у скамьи** (на скамье ↓, на телефоне стик вниз): маска здоровья (до +3, цена растёт), острая игла (+1 урон по обычным врагам, до 2 раз; боссов не касается), лёгкая катушка (нить копится быстрее: 9 → 8 → 7 ударов). Выбор — ↑ ↓, купить — Enter / Пробел / F, закрыть — Esc; геймпад: A / B; на телефоне — тап по строке.
- **Пауза**: меню «Продолжить», «Заново», «Карта», «Снаряжение», «Как играть», «Настройки», «В главное меню» (стрелки / W S / цифры / Enter, крестовина и A, касание). Справка по управлению, приёмам, коопу и боссам теперь в «Как играть» (вкладки; текущее устройство — первым). Игра сама встаёт на паузу, если свернуть вкладку или переключиться в другое приложение (кроме игры по сети).
- **Меню скамьи**: ↑ на скамье (на телефоне стик вверх) открывает «Отдохнуть» / «Лавка» / «Карта и переходы» / «Снаряжение»; по сети меню мир не останавливает. Экран победы — тоже меню: «Дальше» / «Заново» / «В главное меню».
- Игра помнит выбранного в босс-тесте босса; на полосе здоровья босса отмечена вторая фаза; на последнем бутоне здоровья края экрана пульсируют красным.

## Управление

| | Игрок 1 | Игрок 2 (один компьютер) | Геймпад |
|---|---|---|---|
| Ходить | A D W S | стрелки | стик / крестовина |
| Прыжок | Пробел | Num1 или / | A |
| Удар | F | Num2 или . | X |
| Рывок | G | Num3 или , | B / RB |
| Лечение | Q | Num0 или M | Y |
| Дымовая бомба | R | Num4 или N | LB |

В одиночку можно и так: стрелки + Z X C V B. Бомба: ↑ + R — навесом, ↓ + R — под ноги. Esc — пауза. Удар вверх: ↑ + удар. Удар вниз в прыжке даёт отскок от колючек и врагов. Напарника в коконе оживляют, встав рядом и держа ↑ одну секунду.

## Инструменты разработчика (v2)

Всё ниже работает на ядре v2 в чистом Node, без браузера (нужен Node 22+ и `npm ci`).

| Команда | Что делает |
|---|---|
| `npm run bot -- table --fights 200 [--boss misha,vladik,tima,korne] [--skill 0.6]` | ИИ-бот играет боссов на пуле воркеров (ядра − 2); таблица побед, времени боя и обрывов нити с 95 % интервалами (Уилсон, бутстрэп). `--json`, `--balance файл.json` |
| `npm run bot -- watch бой.ttrec` | посмотреть запись боя в браузере тем же движком игры (`?watch=`); без файла — записать бой бота и открыть |
| `npm run fuzz -- --hours 1` (или `--seconds 60`) | фаззер: все режимы, случайный и полуслучайный ввод, инварианты, сверка журнала; находки — минимальными записями в `tests/repro/` |
| `npm run replay -- файл.ttrec` | проиграть запись на ядре и напечатать исход и хэши |
| `npm run sim -- --boss misha --frames 36000` | быстрая симуляция ядра |
| `python ml/tune.py --boss korne --target "skill0.6:winrate=0.55..0.65,time=80..120" --trials 50` | Optuna подбирает баланс через бота, отчёт с графиками в `ml/reports/`; игру не меняет (`ml/README.md`) |

Записи партий `.ttrec`: включите «Настройки → Игра → Записывать мои бои» (или `?rec=1`); формат — `docs/TTREC.md`. Баланс игры — `data/balance.json` (схема проверяется при загрузке).

## Геймпады и Steam Deck

Работает DualSense / DualShock, Xbox и Steam Deck (стандартная раскладка браузера). Геймпад подхватывается после первого нажатия кнопки.

| Действие | Xbox / Deck | PlayStation |
|---|---|---|
| Идти | левый стик / крестовина | левый стик / крестовина |
| Прыжок | A | ✕ |
| Удар (↑/↓ + удар — вверх/вниз) | X | □ |
| Рывок | B, RB, RT | ○, R1, R2 |
| Нить: лечение, отбив, ↑ + нить — всполох | Y, LT | △, L2 |
| Дымовая бомба (арена Миши) | LB | L1 |
| Пауза | Start (Menu) | Options |
| Карта | Back (View) | Create / Share |

Вибрация: урон, отбив, всполох, рёв и оглушение босса (Chrome и Edge; в настройках включается «Вибрация»). Сенсорные кнопки прячутся, пока вы играете геймпадом, и возвращаются при касании экрана.

**Steam Deck.** Откройте игру в Chrome или Firefox. В режиме Gaming добавьте браузер как стороннюю игру в Steam и выберите шаблон управления «Геймпад» (не «Геймпад с мышью»): так браузер увидит кнопки как обычный геймпад. На экране 16:10 по краям остаются небольшие полосы.
