# Промт для агента: как пользоваться ИИ-инструментами «Тропы Ткачей»

Скопируйте всё ниже (между линиями) в начало сессии нового агента.

---

Ты работаешь над игрой «Тропа Ткачей» (метроидвания в браузере; Phaser 4 + TypeScript + Vite + Preact; репозиторий Rus25-dev/tropa-tkachei, сайт https://rus25-dev.github.io/tropa-tkachei/). Отвечай по-русски, коротко и по делу. Сначала прочитай `ai/README.md`, `ml/README.md` (раздел «Нейросеть-игрок (RL)») и `ml/rl/runs/README.md` — там карта и отчёты.

## Что есть и как этим пользоваться

1. **Ядро игры** `src/core/` — детерминированное (шаг 1/60 с, зерно): одно зерно и один ввод дают один исход. Без `Math.random`, `Date`, таймеров, DOM и Phaser (ESLint следит). 49 «золотых» записей v1.8 проходят бит в бит: `npx vitest run`, `npm run legacy:golden` (нужен `$env:CHROME="C:\Program Files\Google\Chrome\Application\chrome.exe"`). Если они разошлись без понятной причины — остановись и сообщи.
2. **Эвристический бот** (`tools/bot/`): «средний игрок» по шкале мастерства 0…1. Таблица побед по боссам: `npm run bot -- table --fights 200 --boss misha,vladik,tima,korne --skill 0.6` (флаги `--json`, `--balance файл.json`). Посмотреть бой бота: `npm run bot -- watch --boss tima --skill 0.9 --seed 3`.
3. **Фаззер** (`tools/fuzz/`): `npm run fuzz -- --seconds 60` (час: `--hours 1`). Находки минимизируются в `tests/repro/*.json`, их проигрывает тест `repro.test.ts`. Две известные особенности v1.8 (поводок напарника, ворота арены Корнематки) помечены `status: known` и не считаются находками.
4. **Записи боёв `.ttrec`** (`docs/TTREC.md`): включить «Настройки → Игра → Записывать мои бои» или `?rec=1`; воспроизвести `npm run replay -- файл.ttrec`; посмотреть в игре `?watch=<файл>` или перетаскиванием файла.
5. **Optuna** (`ml/tune.py`): подбор баланса боссов через бота, `data/balance.json` сама не меняет (менять только после одобрения пользователя: золотые записи v1.8 разойдутся). Окружение: `py -3 -m venv ml/.venv`, `pip install -r ml/requirements.txt`.
6. **Нейросеть-игрок (RL)**:
   - Среда боёв `tools/rl/` (Node, потоки), обучение PPO `ml/rl/train.py` (Python 3.13, PyTorch с CUDA 12.8+ для RTX 50xx, окружение `ml/.venv-rl`), экспорт весов `ml/rl/export.py` → `public/agents/tkachi.json` (**только локально, в .gitignore**), оценка `ml/rl/evaluate.py` и `npm run rl:eval -- --pack public/agents/tkachi.json --boss misha --persona average --fights 200`.
   - Панель наблюдения: `npm run build`, затем `ml/.venv-rl/Scripts/python ml/rl/panel.py`, открыть http://localhost:8765/ — графики обучения, блок «Прогресс обучения» (очередь запусков, лимиты, круги оценки), окно «Агент играет» (настоящая игра воспроизводит записи боёв), кнопка «Запустить гонку двух агентов» (полная Гонка Ткачей в «Босс-раше»: организатор-автомат, два агента и обсервер на локальном PeerJS, порт 9166).
   - Агент в игре: `?agent=tkachi&persona=average|careful|aggressive|novice[&aseed=N&aname=Имя]`. Он детерминирован. Умеет бои с боссами (Корнематка, Миша, Владик, Тима); «Тропа целиком» (бег по уровням) ему недоступна.
   - Продолжить обучение: `ml/.venv-rl/Scripts/python ml/rl/train.py --name misha-avg-1 --resume --minutes 30`; остановить — создать файл `ml/rl/runs/<имя>/stop`. Новый босс или характер — другой `--name`. Награда настраивается (`--reward '{"hurt":1.2}'`), задержка реакции — `--lag`.
7. **Гонки Ткачей** (организатор + 2 игрока + обсервер, дисциплины «Тропа целиком», «Босс-раш», «Дуэль ткачей», Эло, `rating.html`): `?race=org`, `?race=play&room=КОД`, `?race=watch&room=КОД&stream=1`; для агентов добавляй `&agent=tkachi&persona=…`.

## Правила работы (обязательно)

- **Среда.** Windows. В PowerShell перед `node`/`npm`: `$env:Path = "C:\Program Files\nodejs;" + $env:Path`; в Git Bash node недоступен. Файлы читай и пиши в UTF-8 явно (`[IO.File]::ReadAllText($f, (New-Object Text.UTF8Encoding $false))`), PowerShell 5.1 иначе портит кириллицу. Не используй `rm -rf`; папки в корне диска `C:\` Claude Code не даёт удалять.
- **Проверка перед PR:** `npm run verify` (линт, типы, vitest, сборка, e2e; локально идёт на установленном Chrome с видеокартой, около 1,5–2 минут) и золотые записи. В CI на GitHub e2e в несколько раз медленнее (процессор), тяжёлые многооконные тесты там пропускаются (`test.skip(!!process.env.CI)`), упавший тест можно перезапустить.
- **Не запускай два набора браузерных тестов одновременно** (общий мьютекс — каталог `C:\tt-e2e.lock`; порты PeerJS в e2e у каждого набора свои: coop 9155, races 9156, races-layout 9157, agents 9158, duel 9170, панель 9166; не повторяй чужие).
- **Процессор общий:** обучение использует до ~16 потоков; фаззер и Optuna занимают все ядра — не запускай их, пока идут e2e.
- **Игру не менять без согласия:** баланс (`data/balance.json`), поведение ядра и существующие уровни трогай только по прямой просьбе пользователя.
- **Git:** ветки от `main`, PR в `main` (CI: `check`, `fuzz`, `legacy-golden`), сливает координатор после зелёного CI. Коммиты: `git -c user.name="Claude" -c user.email="noreply@anthropic.com" commit`, в конце сообщения `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; тело PR заканчивай `🤖 Generated with [Claude Code](https://claude.com/claude-code)`. Веса, записи боёв и сырые метрики в git не добавляй.
- **Честность:** если что-то не проверено или результат плохой — так и пиши; цифры бери из отчётов и таблиц, не округляй в пользу результата.

## С чего начать

Задай пользователю один вопрос: что нужно — обучить/дообучить агента, снять гонку агентов для трейлера, прогнать таблицу бота и фаззер, подобрать баланс (Optuna) или научить агента проходить «Тропу целиком». Дальше действуй по разделам выше.
