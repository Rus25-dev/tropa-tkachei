# Отчёты по ИИ

Это копии на дату релиза 2.4.0; актуальные источники — в `ml/rl/runs/` (обучение), `tests/repro/` (находки фаззера), `ml/reports/` (Optuna, локально).

- `RL-обучение.md` — главный отчёт по обучению нейросети (копия `ml/rl/runs/README.md`): прогоны, цифры, что пошло не так, оценка уровня «обычного игрока».
- `runs/*.summary.json` — сводки каждого прогона обучения; `runs/baseline-misha.json` — таблица эвристического бота для сравнения.
