# Находки фаззера

Сюда `npm run fuzz` кладёт **минимальные** записи найденных ошибок (`*.json` — файлы `.ttrec` с блоком `repro`, формат в `docs/TTREC.md`).
Каждую проигрывает `tests/unit/repro.test.ts` под теми же инвариантами, что и фаззер.

Разбор находки:
1. `npm run replay -- tests/repro/<имя>.json` — посмотреть исход; `repro.message` в файле — что именно нарушено.
2. Настоящая ошибка ядра, не меняющая поведение v1.8, — исправить и поставить `"status": "fixed"` (тест потребует, что нарушения больше нет).
3. Особенность v1.8, которую менять нельзя, — `"status": "known"` и пояснение в `repro.note` (тест потребует, что она по-прежнему воспроизводится).
4. `"status": "open"` оставляет тест красным: находку нужно разобрать до слияния.
