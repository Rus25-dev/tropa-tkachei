# Запись партии `.ttrec`

`.ttrec` — файл с записью одной партии: зерно, режим, ввод игрока по тикам и действия интерфейса. Ядро игры детерминировано
(один и тот же ввод при том же зерне даёт тот же бой бит в бит), поэтому по записи партию можно:

- **посмотреть в игре** тем же движком: `?watch=<адрес>`, перетаскиванием файла в окно, «Настройки → Игра → Открыть запись…»,
  `npm run bot -- watch файл.ttrec`;
- **проиграть в Node** без браузера и сверить исход и хэши: `npm run replay -- файл.ttrec` (примерно в 6000 раз быстрее реального времени);
- **использовать как тест**: так устроены находки фаззера в `tests/repro/`.

Файл — обычный JSON (UTF-8). Описание формата реализует `src/core/ttrec.ts`; журнал ввода — `src/core/journal.ts`
(тот же формат, что у золотых записей v1.8 и у забегов спидрана).

## Как записать свою партию

1. Включите «Настройки → Игра → **Записывать мои бои**» или откройте игру с `?rec=1`.
2. Когда бой закончится (босс повержен, забег завершён, вы вышли в меню или нажали «Заново» после боя), браузер скачает
   `tt-<бой>-<дата>.ttrec`. Записи короче 5 секунд не сохраняются; тренировка босса не записывается.
3. **Приватность**: файл только скачивается на ваше устройство. Игра ничего не отправляет в сеть, адрес `?watch=` обязан быть
   на том же сайте, что и игра.

Каждая сцена обычной партии — отдельная запись (коридор, арена, «Дальше», «Заново»): новая сцена создаётся из сохранения главы,
его снимок хранится в `setup.progress`. Забег спидрана — один файл на весь забег (сохранение в нём не читается).
Партия вдвоём у одного компьютера записывается так же (`np: 2`).

Ограничения: смена снаряжения на скамье во время записи в журнал не попадает (запись, снятая с переодеванием, может разойтись при воспроизведении);
журнал гонки (`race`) воспроизводится только из окна гонки.

## Формат

```jsonc
{
  "format": "ttrec",            // обязательно
  "v": 1,                       // версия формата
  "ver": "2.0.0",               // версия игры, в которой снята запись
  "meta": {
    "kind": "player",           // player | bot | fuzz | repro
    "label": "Босс-тест · Миша",// подпись для человека
    "boss": "misha",            // босс, если это бой
    "skill": 0.9,               // мастерство бота (kind: bot)
    "created": "2026-10-21T15:30:00.000Z", // ставит приложение
    "note": "…"                 // пояснение (находки фаззера)
  },
  "setup": {                    // всё, что не лежит в журнале, но влияет на партию
    "easy": false,              // «лёгкий режим»
    "loadout": { "weapon": "needle", "tool": "", "charms": [], "have": { "weapons": [], "tools": [], "charms": [] } }, // tt_loadout
    "progress": null,           // tt_save на момент создания первой сцены (точка возрождения, бусины, способности)
    "balance": { }              // переопределение баланса — только записи инструментов (бот, Optuna); игра такие записи не открывает
  },
  "journal": { … },             // журнал ввода, см. ниже
  "expect": { … }               // ожидаемый исход (core/journal.ts outcome): по нему проверяется воспроизведение
}
```

### `journal`

```jsonc
{
  "v": 1, "ver": "…", "mem": true,   // mem: true — богатые контрольные хэши (hv: 2)
  "cat": null,                       // null | "trail" | "boss": забег спидрана
  "race": null, "seed": 123456789,
  "segs": [{                         // отрезки = сцены; у обычной записи один, у забега — по числу сцен
    "seed": 123456789, "np": 1, "hv": 2,
    "data": { "players": 1, "mode": "bosstest", "boss": "misha", "camp": null },   // как создавать сцену
    "n": 5000,                       // число тиков (1 тик = 1/60 с)
    "rle": [value, repeats, …],      // ввод по тикам: пары «значение — сколько тиков подряд»
    "acts": [[tick, "name", a, b, c], …],  // действия интерфейса и «ходы» записи
    "chk": [tick, hash, …]           // контрольные хэши состояния каждые 300 тиков
  }],
  "splits": [], "pauses": []
}
```

`value` — ввод первого игрока: 10 бит удержания (`left, right, up, down, jump, atk, dash, heal, bomb, tool`) и 7 бит фронтов
нажатий (`jumpP, atkP, dashP, healP, upP, bombP, toolP`), `raw | pend << 10`. У двух игроков ввод второго добавлен старшими разрядами (`× 131072`).

Действия `acts`: `T` пауза, `bc` закрыть меню скамьи, `br` отдых (герой, скамья, тихо), `so`/`sc` открыть/закрыть лавку, `sb` купить,
`mo`/`mc`/`mm`/`mg` карта, `tp`/`rel` техпауза и «пошёл» гонки; `ex` — отладочные ходы записи (`ex 1` довести босса до последнего удара,
`ex 10` героев к арене Корнематки, `ex 20 x y` перенос героя). Список — `tests/golden/README.md`.

## Воспроизведение

```
npm run replay -- файл.ttrec            # исход, хэш итогового состояния, сверка с expect
npm run replay -- файл.ttrec --hashes   # плюс контрольные хэши по тикам
npm run replay -- файл.ttrec --json     # то же в JSON
```

Код выхода 1, если запись не проигралась (состояние разошлось с контрольным хэшем) или исход не совпал с `expect`.
`npm run replay` понимает и золотые записи `tests/golden/*.json`.

В игре запись проигрывает `ReplaySession` (`src/core/replaysession.ts`): ввод берётся из журнала, действия игрока отключены.
Панель внизу: пауза просмотра, скорость ×0,5 / ×1 / ×2 / ×4, «с начала», «выйти».

## Проверка структуры

`ttrecError()` отвергает файл, если: нет `format: "ttrec"`/`v: 1`; `meta.kind` не из списка; у отрезка неверные `seed`, `np` (1–2), `hv` (1–2),
`data.mode` (`story` | `bosstest`); `rle` не парами, повторов меньше 1 или их сумма не равна `n`; `acts` не вида `[тик, имя, a, b, c]`;
всего больше 5 часов игрового времени (защита от файла, который повесит воспроизведение).
