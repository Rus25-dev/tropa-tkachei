# Данные боссов (каркас 2.5)

Босс на данных — это один JSON в `data/bosses/` (схема на zod: `src/core/boss/schema.ts`) плюс общий исполнитель в ядре (`src/core/boss/exec.ts`). Ни одного числа боя в коде нет: замахи, удары, снаряды, движение, связки и фазы лежат в файле. Старые боссы (Корнематка, Миша, Владик, Тима) пока остаются ручными автоматами; их перенос на каркас — версия 2.6.

Единицы: **время — в кадрах** (60 в секунду), расстояния — в пикселях мира (тайл = 32 px), углы — в градусах.

## Как посмотреть манекена

`?dev=1` в адресе → «Босс-тест» → карточка «Манекен-наставник (dev)». Рекомендуется включить «Тренировку» (клавиша T): видно название последнего телеграфа и счётчик урона, фаза старта выбирается клавишей P. В Node: `npm run sim -- --boss dummy --frames 36000`. По сети манекен не поддержан.

## Язык атаки (`Attack`)

```
id, name?                    — идентификатор и название для тренировки
tell:     { frames, cue: { color, sfx, pose }, lockFace? }          — замах
active:   [{ from, to, hit: Box, dmg, kind, knock? }]               — удары (кадры от конца замаха, включительно)
move:     [{ from, to, vx, vy, toward }]                            — движение босса
spawn:    [{ at, proj, kind, from, ox, oy, vx, vy, aim, count, spread, dmg? }]   — снаряды
recovery: { frames, punishWindow: { from, to } }                    — восстановление и окно наказания
requires: { dist?, phase?, arenaSide?, hpBelow? }                   — условия, при которых атаку можно начинать
```

Порядок кадров: **замах** (`tell.frames`) → **рабочая часть** (кадры `0…E`, где `E` — последний из `active.to`, `move.to`, `spawn.at`) → **восстановление** (`recovery.frames`). Урон наносится только в кадрах `active`, снаряды появляются в кадр `spawn.at`.

- **`tell.cue.color`**: `yellow` — парируемое, `red` — только уворот, `purple` — неотбиваемое, `white` — нейтральный замах (в играх лучших боссов одинаковый замах у разных приёмов — осознанная «обманка»). Цвет определяет контур тела и мигание в замахе (вид: `drawDataBoss`). `sfx` — имя звука, `pose` — имя позы (для арта босса). `lockFace`: взгляд фиксируется в начале замаха, иначе босс следит за героем до конца замаха, а к первому активному кадру разворот фиксируется.
- **`kind`** (тип удара, `HitKind`): `parry` — можно отбить; `dodge` — только уворот; `unblockable` — не отбивается и не гасится рывком, только избежать. Он идёт в `hurtPlayer(sc, p, dmg, srcX, spike, hk)` и в снаряды (`Proj.hk`). Что делает с типом удара герой (идеальный отбив, цвета) — логика Парирования 2.0, каркас лишь проставляет `hk`.
- **`Box`**: `{ x, y, w, h, at }`. `at: "self"` (по умолчанию) — `x` отсчитывается от центра босса *вперёд* (зеркалится по взгляду; левый край при взгляде влево — `центр − x − w`), `y` — от верха босса. `at: "target"` — от центра ближайшего героя на момент конца замаха (удар «в место, где стоял герой»), без зеркала.
- **`knock`**: `{ vx, vy }` — отброс героя, если удар попал: `vx` направлен от босса.
- **`move`**: `toward: "player"` — знак `vx` относительно направления на героя (направление берётся в первый кадр отрезка); `"wall"` — к ближайшей к боссу стене; `"fixed"` — `vx` в мировых осях. Ненулевой `vy` в первый кадр отрезка задаёт импульс (прыжок); гравитация — всегда. Вне отрезков на земле `vx = 0`.
- **`spawn`**: `proj` — `{ kind, w, h, life }` (`kind` — вид снаряда ядра: `spore` — дуга под гравитацией, `wave` — прямо по горизонтали до стены, `rock` — падающий камень, `note` и `glob` — дуги; `life` в кадрах); `kind` — тип удара снаряда; `from: "self"` — от центра босса (`ox` вперёд, `oy` по высоте), `"target"` — от точки героя (`oy: -300` — камень сверху над ним); `vx` зеркалится по взгляду для `self`; `aim: true` — целиться в героя (длина скорости `hypot(vx, vy)`); `count` и `spread` — веер из `count` снарядов с углом `spread` между соседними; `dmg` — урон снаряда (по умолчанию 1, у тяжёлых видов — 2, как в `HEAVY_KINDS`). Место появления сдвигается вниз, если оказалось в стене.
- **`recovery.punishWindow`**: кадры восстановления (с нуля), в которые босс беззащитен для серии ударов; в них `DState.punish = true` (зелёное кольцо у ног манекена, бот и тесты используют флаг).

### Правила честности (`data/bosses/rules.json`)

Загрузка босса отклоняется, если нарушены минимумы: замах не короче `minTellFrames` для самого строгого типа удара атаки (`parry` 20, `dodge` 24, `unblockable` 30), восстановление не короче `minRecoveryFrames`, окно наказания не короче `minPunishFrames` и целиком внутри восстановления; кроме того проверяются ссылки (атака, связка, `enterChain`), порядок порогов фаз, `from ≤ to` и пустые атаки.

## Связки и политика

```
Chain:  { id, steps: [{ attack, gapFrames? }], weight, requires?, cooldown? }
Policy: { chains: [id…], noRepeat, fatigue?, restFrames: [min, max], priority: [{ chain, closeDist, closeFrames }] }
```

- `gapFrames` — пауза после шага до следующего замаха (по умолчанию — всё восстановление шага); так делаются быстрые комбо. У последнего шага работает полное восстановление и окно наказания.
- **Выбор** (`policy.ts`, `pickChain`): ровно одно обращение к `sc.rngFor('boss')` на выбор. Допустимы только связки из `policy.chains`, у которых выполнены `requires` связки и `requires` её первой атаки, нет перезарядки (`cooldown` кадров) и нет среди последних `noRepeat` выбранных. Если таких нет — `noRepeat` ослабляется (запрещена лишь самая последняя связка); если нет вообще никого, босс ждёт (**сухое правило**: недопустимая связка не выбирается ни при каком броске). `dist` проверяется только у первого шага связки.
- **`fatigue`**: вес связки умножается на `factor` за каждое недавнее использование; одно использование «забывается» за `decay` кадров.
- **`priority`** («отогнать»): если герой ближе `closeDist` px подряд `closeFrames` кадров, выбирается связка `chain`, минуя веса (но с учётом её `requires` и перезарядки).
- **`requires`**: `dist: [мин, макс]` (по горизонтали до ближайшего героя), `phase: [номера]`, `arenaSide: left|center|right` (треть арены, где стоит босс), `hpBelow` (доля здоровья).

## Фазы и босс

```
Phase:   { fromHp, rageFrames?, scene?: { frames, skippable, say? }, enterChain?, policy }
BossDef: { id, name, about, arena, size, hp: [1 герой, 2 героя], color, music?, intro: { frames, say? }, deathFrames,
           idle: { walkSpeed, keepDist }, contact?: { dmg, kind }, attacks, chains, phases (1–3) }
```

Фаза включается, когда `hp / maxHp ≤ fromHp` (у первой — 1). Переход использует общие правила `bosses2.ts`: рёв, неуязвимость на `rageFrames`, сброс снарядов, отталкивание героев; затем пропускаемая вставка-сцена (`scene`, пропуск прыжком или ударом), затем **переходный приём** `enterChain` — обычная связка с телеграфом, потом политика новой фазы. Стойкость, оглушение (текущая атака обрывается), двойной урон по оглушённому и казнь работают как у остальных боссов; замедление растягивает время исполнителя (кадры идут реже). `arena` берёт уровень арены из `levels/tropa.ldtk` (`misha`, `vladik`, `tima`) и точку появления босса из него.

## Состояние исполнителя

Лежит в `boss['d']` (`DState`, только данные): `mode` (`intro`, `idle`, `rage`, `scene`, `attack`, `dead`), `atk`, `af` (кадр атаки), `chain`, `step`, `punish`, `cue`, `mem` (история связок, перезарядки, усталость). `boss.state` для остального кода: `intro`, `idle`, `tell`, `active`, `recover`, `rage`, `dead`.

## Пример (сокращённо, `data/bosses/dummy.json`)

```json
{
  "id": "dummy", "name": "Манекен-наставник", "arena": "vladik",
  "size": { "w": 40, "h": 78 }, "hp": [24, 34], "intro": { "frames": 120 },
  "attacks": [{
    "id": "swing", "name": "Взмах",
    "tell": { "frames": 26, "cue": { "color": "yellow", "sfx": "swing", "pose": "raise" } },
    "active": [{ "from": 0, "to": 5, "hit": { "x": 6, "y": 14, "w": 72, "h": 56 }, "dmg": 1, "kind": "parry" }],
    "recovery": { "frames": 32, "punishWindow": { "from": 6, "to": 27 } },
    "requires": { "dist": [0, 130] }
  }],
  "chains": [{ "id": "c_combo", "steps": [{ "attack": "swing", "gapFrames": 14 }, { "attack": "thrust" }], "weight": 3 }],
  "phases": [{ "fromHp": 1, "policy": { "chains": ["c_combo"], "noRepeat": 0, "restFrames": [30, 54] } }]

```

Манекен: 8 атак (взмах, выпад — жёлтые; удар оземь, каменный дождь, рывок — красные; три шара — жёлтые снаряды; сокрушение — фиолетовое; отталкивание — белый замах, «отогнать»), 7 связок и переходная, две фазы (вторая с 55 % здоровья добавляет «Сокрушение» и укорачивает паузы).

## Как добавить босса

1. Положить `data/bosses/<id>.json` и подключить в `src/core/boss/registry.ts` (`registerBoss(...)` проверит схему и правила честности при загрузке).
2. Нарисовать фигуру в `src/view/draw/bosses.ts` (телеграф и контуры универсальны: `drawDataBoss` годится как основа).
3. Тесты: `tests/unit/boss-*.test.ts` — образцы для схемы, кадров исполнителя, выбора связок, фаз и симуляции в Node.
