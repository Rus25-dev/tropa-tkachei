# Производительность v2.0 против v1.8

Замеры: `tools/perf.mjs` (v2) и `tools/perf-legacy.mjs` (v1.8). Кадры считаются по `requestAnimationFrame` за 5 секунд после 2,5–3 с прогрева сцены.
Железо — рабочий ПК разработчика с видеокартой; «замедление CPU ×N» — `Emulation.setCPUThrottlingRate` в протоколе DevTools (имитация слабого телефона),
«телефон 844×390 @2×» — окно 844×390 с devicePixelRatio 2. Живые данные игры (время логики и отрисовки, число объектов, память) показывает `?perf=1` в левом нижнем углу.

## Кадры в секунду: v2 / v1.8

| Сцена | ПК, ×4, высокое | ПК, ×6, высокое | ПК, ×6, авто | телефон 844×390 @2×, ×4, авто | телефон 844×390 @2×, ×6, авто |
|---|---|---|---|---|---|
| заставка меню | 60 / — | 60 / 60 | 60 / 60 | 60 / 60 | 60 / 60 |
| глава I (один) | 60 / — | **53 / 35** | **50 / 35** | 60 / 59 | **56 / 34** |
| босс: Миша (v2 — фаза 3, v1.8 — фаза 1) | 60 / — | 58 / 60 | 51 / 60 | 53 / 60 | 51 / 60 |
| босс: Тима (v2 — фаза 3, v1.8 — фаза 1) | 60 / — | 60 / 55 | 60 / 55 | 60 / 60 | 60 / 53 |
| вдвоём, глава I | 60 / — | 48 / 34 | **58 / 34** | 60 / 58 | **58 / 33** |

Сырые данные — `docs/perf/*.json` (поле `hud` — строка `?perf=1`: время логики и отрисовки за кадр, число объектов, память).

## Что видно

- Без замедления обе версии держат 60 кадров в секунду во всех сценах. Логика одного тика стоит около 0,09 мс; отрисовка — 0,2 мс в обычной сцене и до 2,8 мс в третьей фазе Миши. Память 67–87 МБ.
- При замедлении ×6 v2 в главе I даёт 50–53 кадра там, где v1.8 — 35; вдвоём v2 с «Авто» держит 58 против 34. Причина: карта уровня рисуется один раз в текстуры-куски, а не каждый кадр, и всё идёт через WebGL.
- Единственные сцены, где v2 на слабом устройстве слабее v1.8, — бой с Мишей в третьей фазе (51 против 60 при ×6): много частиц и текстовых объектов («буквы»). Это в списке доработок: пул текстов и GPU-слой спрайтов для букв.
- Сравнение босс-сцен не совсем честное: у v2 замер идёт в третьей фазе тренировки (самой тяжёлой), у v1.8 такой режим не существует, поэтому там фаза 1.
- «Авто» снижает качество, если кадров меньше 55 дольше 2 секунд; на телефоне стартует со «Среднего» (без виньетки и свечения), на ПК — с «Высокого».
- Размер сборки: `dist/index.html` ≈ 1,7 МБ (gzip ≈ 0,5 МБ) одним файлом, Phaser внутри; у v1.8 файл 0,87 МБ, но Phaser 3 грузился с CDN.

## Как повторить

```
npm run build
$env:CHROME="C:\Program Files\Google\Chrome\Application\chrome.exe"
node tools/perf.mjs 1280x720 6 auto 1 > docs/perf/v2-1280x720-x6-auto-d1.json
node tools/perf-legacy.mjs 1280x720 6 1 > docs/perf/v18-1280x720-x6-d1.json
```
